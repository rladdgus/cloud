# 유튜브 쇼츠 채널 자동 운영

컴퓨터를 켜 두면 알아서 **주제 선정 → 대본 작성 → 사실 확인·정책 검수 → 음성·영상 제작 → 업로드 → 댓글 관리 → 조회수 분석**을 반복합니다.

## 채널 전략: "1분 호기심" (한국어 지식 쇼츠)

한 채널 안에서 5개 시리즈를 돌아가며 올리고, **조회수가 잘 나오는 시리즈를 자동으로 더 자주** 만듭니다.

| 시리즈 | 이유 |
|---|---|
| 알고 보면 신기한 동물 | 아이·가족 시청층까지 잡을 수 있고, 조회수가 가장 안정적인 장르 |
| 1분 과학·우주 | "왜?" 질문형 훅이 강하고 소재가 무한함 |
| 역사 속 황당한 순간 | 공유·댓글이 많이 달리는 장르 |
| 내 몸의 비밀 | 검색 수요가 높음 (의료 조언은 금지) |
| 심리학 한 조각 | 저장·공유율이 높음 |

**키즈 채널로 만들지 않은 이유:** YouTube에서 "아동용"으로 지정하면 **댓글이 꺼지고**(댓글 자동화 불가), 맞춤 광고가 막혀 수익이 크게 줄어듭니다. 또 AI로 대량 생산한 아동용 영상은 YouTube가 특히 엄격하게 단속하고 있어요. 대신 동물 시리즈를 온 가족이 보기 좋은 톤으로 만들어서 키즈 시청층의 장점만 가져갑니다.

주제·말투·업로드 시각은 `config.yaml`에서 바꿀 수 있어요.

## 처음 한 번만 하는 설정 (약 20분)

### 1. Python 설치
[python.org](https://www.python.org/downloads/)에서 설치하세요. **"Add Python to PATH"를 꼭 체크**해야 해요.

### 2. 이 폴더 받기
GitHub에서 **Code → Download ZIP**을 눌러 받은 뒤 압축을 풀어요.

### 3. Claude API 키
1. https://console.anthropic.com 에 가입하고 결제 수단을 등록하세요.
2. **API Keys**에서 키를 만드세요.
3. `.env.example` 파일을 복사해 이름을 `.env`로 바꾸고, `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣으세요.
4. (선택) [Pexels](https://www.pexels.com/api/)에서 무료 키를 받아 `PEXELS_API_KEY`에 넣으면 배경에 실제 사진이 들어가요. **강력 추천합니다.**

### 4. YouTube 연결
1. https://console.cloud.google.com 에서 새 프로젝트를 만드세요.
2. **API 및 서비스 → 라이브러리**에서 **YouTube Data API v3**를 사용 설정하세요.
3. **OAuth 동의 화면**: 외부(External)를 선택하고, 테스트 사용자에 본인 Gmail을 추가하세요.
   - 테스트 상태로 두면 로그인이 7일마다 만료돼요. **앱 게시(Publish app)**를 눌러 두면 계속 유지됩니다.
4. **사용자 인증 정보 → OAuth 클라이언트 ID → 데스크톱 앱**을 만들고, JSON 파일을 받아 이 폴더에 `client_secret.json`으로 저장하세요.
5. `start.bat auth`를 실행하면 브라우저가 열려요. 채널 계정으로 로그인해 권한을 허용하세요.

> **업로드 영상이 "비공개"로 잠기는 경우:** Google이 아직 검토하지 않은 프로젝트로 올린 영상은 비공개로 잠길 수 있어요. 이럴 때는 YouTube API 서비스 감사(Audit) 신청이 필요합니다.

### 5. (선택) 휴대폰 알림
텔레그램에서 @BotFather로 봇을 만들어 토큰을 받고, 봇에게 메시지를 한 번 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates`에서 chat id를 확인하세요. 둘 다 `.env`에 넣으면 업로드 완료와 오류 알림이 휴대폰으로 와요.

## 사용법

| 명령 | 하는 일 |
|---|---|
| `start.bat test` | 영상 1개를 만들기만 함 (업로드 안 함). `output/` 폴더에서 확인 |
| `start.bat once` | 영상 1개를 만들어 바로 업로드 |
| `start.bat` | **자동 운영 시작.** 이 창을 켜 둔 채로 두세요 |

Mac·Linux에서는 `start.bat` 대신 `./start.sh`를 쓰세요.

**처음에는 `test`로 영상 2~3개를 직접 보고 품질을 확인한 뒤** `start`를 실행하세요.

## 동작 방식

- **업로드:** `config.yaml`의 `upload_times` 시각마다 1개씩 올려요. 기본값은 하루 2개(12:30, 19:30)예요.
- **검수:** 별도 검수 AI가 웹 검색으로 사실을 확인하고, 정책·품질을 10점 만점으로 매겨요. 8점 미만이면 다시 쓰고, 끝내 통과하지 못하면 그 회차는 올리지 않아요.
- **댓글:** 30분마다 새 댓글을 확인해서 질문과 칭찬에는 답글을 달고, 스팸이나 욕설은 "검토 대기"로 숨겨요.
- **분석:** 6시간마다 조회수를 모아 시리즈 선택 비율을 조정해요.
- **AI 표시:** AI 음성을 쓰므로 업로드할 때 "합성 콘텐츠" 표시를 자동으로 켜요. YouTube 정책상 필요합니다.
- 컴퓨터가 절전 모드로 들어가지 않게 막아요. 오류가 나도 다음 회차는 계속 진행돼요.
- 기록은 `data/ytauto.log`에 남아요.

## 비용 (대략)

- Claude API: 영상 1개에 약 $0.05~0.20 (웹 검색 포함). 하루 2개면 한 달에 약 $3~12예요.
- 음성(Edge TTS), 배경 사진(Pexels), YouTube API는 무료예요.
- YouTube API 무료 한도로는 하루 약 6개까지 업로드할 수 있어요.

## 알아둘 점

- 성과는 보장되지 않아요. 쇼츠는 보통 30~100개쯤 올려야 알고리즘 반응이 보이기 시작해요.
- YouTube의 "반복적·대량 생산 콘텐츠" 정책 때문에 수익 창출 심사에서 떨어질 수 있어요. 가끔 직접 영상을 보고, 반응이 좋은 영상 스타일로 `config.yaml`의 `brief`를 다듬어 주면 훨씬 유리해요.
- 배경 음악은 저작권 없는 음악만 쓰세요. YouTube 오디오 보관함 음악을 추천해요.
