# 운영 설계: "오늘의 살림템" 쇼핑 쇼츠 채널

## 1. 한 줄 요약
쿠팡 상품 사진 한 장으로 **AI가 대본을 쓰고 광고 심의를 거친 뒤, 움직이는 제품 영상에 단어 단위 자막과 음성을 입혀** 하루 2개씩 올려요. 쿠팡 파트너스 수수료가 주 수익원이고, 구독자 1,000명과 쇼츠 조회수 1,000만 회를 넘기면 YouTube 광고 수익이 더해져요.

## 2. 누가 무엇을 하나

| 담당 | 하는 일 | 빈도 |
|---|---|---|
| **사용자** | 계정 만들기, API 키 입력, 처음 영상 5~10개 직접 확인 | 처음 한 번 + 가끔 |
| **프로그램** (`run.py start`) | 상품 선택 → 대본 → 심의 → 영상 → 업로드 → 링크 댓글 → 댓글 답변 → 조회수 수집 | 자동 (하루 2회 업로드, 30분마다 댓글) |
| **Cowork** (선택) | API로 할 수 없는 일: 쿠팡 API가 열리기 전의 링크 만들기, 링크 댓글 고정, 주간 성과 점검 | 매일 / 매주 |

## 3. 영상 제작 방식 비교

| 방식 | 영상 1개 비용 | 장점 | 단점 |
|---|---|---|---|
| **자체 스튜디오 + Kling** (기본값) | 약 $0.7~1.0 (움직이는 클립 2개 + Claude) | 영상마다 모양이 달라 "반복 콘텐츠" 판정에 유리. 자막·구성을 원하는 대로 바꿀 수 있음. 한국어 자막 정확 | 아바타(사람)가 나오지 않음 |
| 자체 스튜디오 (사진만) | 약 $0.05 | 거의 무료 | 화면이 정적이라 시청 지속률이 낮을 수 있음 |
| Topview | 5크레딧 + 월 구독 | 제품 링크만 넣으면 아바타 광고 완성 | 쿠팡 페이지 인식이 불확실하고 결과물이 템플릿처럼 비슷해짐 |
| Creatify | 약 $1/영상 (API 월 $99부터) | 링크 → 영상 API가 가장 성숙 | 월 고정비. 한국어 품질 확인 필요 (미연동) |
| HeyGen / Arcads | $3~11/영상 | 아바타 품질 최고 | 비쌈. 쇼핑 쇼츠에는 과함 |

**결론:** 처음에는 **자체 스튜디오 + Kling**으로 시작해요. 한 달 60개면 약 $50~60이에요. 반응이 오는 카테고리가 생기면 그 카테고리만 Topview 아바타 영상을 섞어 A/B 테스트할 수 있어요 (`shopping.engine: topview`).

## 4. 영상 한 편의 구성 (25~40초)
1. **0~3초 훅:** 공감되는 불편함 한 마디 + 움직이는 제품 클립 (Kling)
2. **해결:** 제품이 문제를 어떻게 해결하는지
3. **장점 2~3개:** 말하는 단어만 크게 뜨는 자막
4. **마무리:** "링크는 설명란" 안내

화면 위에는 광고 표시와 훅 제목이 계속 떠 있고, 아래에는 진행 막대가 있어요.

## 5. 지키는 규칙 (계정 정지·과태료 방지)
- **표시광고법:** 가짜 사용 후기, "최저가"·"1위", 효능 주장은 쓰지 않아요. 심의 AI가 걸러요.
- **광고 표시:** 영상 위 "광고" 문구, 설명란 쿠팡 필수 문구, YouTube "유료 PPL 포함" 표시를 모두 켜요.
- **AI 표시:** 합성 콘텐츠 표시를 켜요.
- **반복 콘텐츠:** 매번 다른 훅·연출·클립을 써요. 가끔 사람이 직접 확인하는 게 가장 좋은 보험이에요.
- **Kling 클립:** 제품 모양을 바꾸지 말라는 지시를 항상 붙여요. 그래도 실제와 다르게 보이면 `studio.motion.enabled: false`로 끄세요.

## 6. 단계별 계획

| 시기 | 목표 | 할 일 |
|---|---|---|
| 1주차 | 준비 | 채널 개설 → `run.py channel` → `test`로 영상 5개 확인 → 품질이 괜찮으면 `start` |
| 2~4주 | 30~50개 업로드 | 조회수 수집으로 잘되는 카테고리 파악. 링크 댓글 고정 (Cowork 또는 직접) |
| 누적 판매 15만 원 | 쿠팡 API 열림 | `.env`에 쿠팡 키 입력 → 상품 고르기까지 완전 자동 |
| YouTube 쇼핑 자격 충족 | YouTube 쇼핑 | YouTube 쇼핑 제휴 프로그램 조건(구독자 수 등, YouTube 고객센터에서 확인)을 채우면 제품 태그 추가 검토 |
| 구독자 1,000명 이상 | 광고 수익 | 쇼츠 조회수 조건을 채우면 YPP 신청 |

## 7. 비용 (하루 2개, 한 달 60개 기준)
- Claude API: 약 $2~5
- Kling (fal.ai): 약 $42 (클립 2개 × 60개). 1개로 줄이면 $21
- 음성: 무료 (Edge). ElevenLabs를 쓰면 월 $5~22 요금제
- **합계 약 월 $45~70.** 사진만 쓰면 약 $5

## 8. 사용자가 준비할 것
1. Google 계정 → YouTube 채널 (브랜드 계정 추천) → 휴대폰 인증
2. Anthropic API 키
3. fal.ai API 키 (움직이는 클립용, 선택이지만 추천)
4. 쿠팡 파트너스 가입 → 채널 승인
5. (선택) ElevenLabs, Topview, 텔레그램 봇
