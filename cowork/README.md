# Cowork 예약 작업 설정

API가 없거나 사람이 눈으로 봐야 하는 일은 Claude **Cowork**가 맡아요. Cowork가 컴퓨터에서 Chrome을 직접 조작해 처리합니다.

## 하루 흐름

| 시각 | 누가 | 하는 일 |
|---|---|---|
| 09:00 | Cowork `01` | 쿠팡 파트너스에서 상품을 골라 `products.txt`에 링크 추가 |
| 12:30, 19:30 | 프로그램 | 영상 제작 → `output/날짜-시각/` 폴더에 영상과 `업로드정보.txt`를 만들고 `READY` 표시 |
| 13:30, 20:30 | Cowork `02` | `READY` 영상을 검수 → 통과하면 YouTube Studio에 업로드하고 링크 댓글 고정, 떨어지면 사유 기록 |
| 22:00 | Cowork `03` | 오늘 달린 댓글 점검, 고정 댓글 확인 |
| 월요일 10:00 | Cowork `04` | 지난주 성과 분석, 설정 조정, 보고서 작성 |

## 처음 한 번 준비
1. **Claude 데스크톱 앱**을 설치하고 **Cowork** 탭을 여세요.
2. Cowork의 작업 폴더로 **이 프로젝트 폴더**를 지정하세요.
3. Chrome에 **Claude in Chrome** 확장을 설치하고 켜 두세요.
4. Chrome에서 아래 두 곳에 **로그인 상태를 유지**해 두세요. Cowork는 비밀번호를 입력하지 않아요.
   - 쿠팡 파트너스: https://partners.coupang.com
   - YouTube Studio: https://studio.youtube.com (채널 계정으로)
5. `config.yaml`에서 `upload.method: cowork`인지 확인하세요. 이게 기본값이에요.

## 예약 작업 등록 방법
Cowork에서 **예약 작업(Scheduled task) → 새 작업**을 누르고, 아래 파일의 내용을 **통째로 복사해서** 지시문에 붙여 넣으세요.

| 작업 이름 | 붙여 넣을 파일 | 반복 |
|---|---|---|
| 상품 링크 채우기 | `01-상품-링크-채우기.md` | 매일 09:00 |
| 영상 검수·업로드 (점심) | `02-영상-검수-업로드.md` | 매일 13:30 |
| 영상 검수·업로드 (저녁) | `02-영상-검수-업로드.md` | 매일 20:30 |
| 댓글 관리 | `03-댓글-관리.md` | 매일 22:00 |
| 주간 점검 | `04-주간-점검.md` | 매주 월요일 10:00 |

모든 작업은 시작할 때 `00-공통-규칙.md`를 먼저 읽도록 되어 있어요. 이 파일은 따로 등록하지 않아도 돼요.

## 꼭 알아둘 것
- 로컬 파일과 Chrome을 쓰는 작업이라 **컴퓨터가 켜져 있고 Chrome이 열려 있을 때만** 실행돼요. 절전 모드로 두지 마세요.
- 처음 1주일은 Cowork가 올린 영상을 하루에 한 번 직접 확인해 주세요. 검수 기준이 너무 느슨하거나 빡빡하면 `02` 파일의 체크리스트를 고치면 돼요.
- 모든 작업은 `cowork/기록/` 폴더에 날짜별 기록을 남겨요. 문제가 생기면 여기부터 보세요.
