# 모든 Cowork 작업의 공통 규칙

이 채널은 "오늘의 살림템"이라는 한국어 쇼핑 쇼츠 채널이에요. 쿠팡 파트너스 제휴 링크로 수익을 내요. 영상은 이 폴더의 Python 프로그램이 만들고, 너(Cowork)는 사람의 눈과 손이 필요한 일을 맡아.

## 폴더 구조 (읽기 전용 표시가 없는 것만 고쳐도 돼)
- `config.yaml`: 채널 설정. **주간 점검 작업만** 정해진 항목을 고칠 수 있어.
- `products.txt`: 영상으로 만들 상품 링크 목록. **상품 링크 채우기 작업만** 맨 아래에 추가할 수 있어. 기존 줄은 지우거나 고치지 마.
- `output/날짜-시각/`: 프로그램이 만든 영상 폴더.
  - `final.mp4`: 완성 영상
  - `script.json`: 대본 (장면별 내레이션, 자막, 제목, 설명)
  - `업로드정보.txt`: YouTube Studio에 그대로 옮겨 적을 내용
  - `READY`: 이 파일이 있으면 "검수·업로드 대기 중"이라는 뜻
- `data/state.json`: 프로그램 상태 (**읽기 전용**, 절대 고치지 마)
- `data/ytauto.log`: 프로그램 로그 (**읽기 전용**)
- `cowork/기록/`: 네 작업 기록을 남기는 곳

## 절대 하지 말 것
1. 비밀번호, 인증번호, 결제 정보를 입력하지 마. 로그인 화면이 나오면 그 작업을 멈추고 기록에 "로그인 필요"라고 남겨.
2. 상품을 구매하거나, 장바구니에 담거나, 쿠팡·YouTube 계정 설정을 바꾸지 마.
3. YouTube에서 영상 삭제, 채널 설정 변경, 수익 창출 설정 변경, 다른 채널 구독·댓글은 하지 마.
4. `data/` 폴더와 `ytauto/` 폴더의 코드 파일, `.env` 파일은 고치지 마. `.env`는 열어 보지도 마.
5. 확신이 없으면 **하지 않는 쪽**을 골라. 애매한 상황은 기록에 적고 다음 사람이 판단하게 해.

## 기록 남기는 법
작업이 끝나면 `cowork/기록/YYYY-MM-DD.md` 파일 맨 아래에 이어서 적어. 파일이 없으면 새로 만들어.

```
## HH:MM 작업이름
- 한 일: (한 줄씩)
- 문제: (없으면 "없음")
- 사람이 확인할 것: (없으면 "없음")
```

## 브라우저 사용 요령
- 새 탭에서 작업하고, 끝나면 네가 연 탭만 닫아.
- 화면 구성은 가끔 바뀌어. 버튼 이름이 설명과 조금 달라도 같은 뜻이면 그걸 눌러. 전혀 찾을 수 없으면 멈추고 기록해.
- 페이지가 느리면 최대 30초까지 기다려. 그래도 안 되면 새로고침을 한 번만 해.
