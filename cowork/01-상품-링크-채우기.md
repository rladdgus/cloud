# 작업: 상품 링크 채우기 (매일 09:00)

먼저 이 폴더의 `cowork/00-공통-규칙.md`를 읽고 그 규칙을 지켜.

## 목표
영상으로 만들 쿠팡 상품 링크가 **항상 6개 이상** 대기하도록 `products.txt`를 채워.

## 1단계: 남은 개수 세기
1. `products.txt`를 열어. `#`으로 시작하는 줄과 빈 줄은 설명이니 무시해.
2. 나머지 줄의 맨 앞(첫 `|` 앞)이 상품 링크야.
3. `data/state.json`을 열어 `used_products` 목록을 봐. 여기 있는 링크는 이미 영상으로 만든 거야. (파일이나 항목이 없으면 쓴 게 없는 거야.)
4. `products.txt`의 링크 중 `used_products`에 **없는** 것의 개수를 세.
5. **6개 이상이면** 기록에 "대기 N개, 추가 안 함"만 남기고 작업을 끝내.
6. 6개 미만이면 **8개를 새로 추가**해.

## 2단계: 상품 고르기
1. Chrome 새 탭에서 https://partners.coupang.com 을 열어. 로그인이 안 돼 있으면 멈춰 (공통 규칙 1번).
2. `config.yaml`의 `shopping.coupang_categories`를 봐. 숫자별 카테고리는 아래와 같아.
   - 1013 주방용품 · 1014 생활용품 · 1015 홈인테리어 · 1016 가전디지털 · 1029 반려동물용품
3. 파트너스 화면에서 **상품 링크 → 카테고리별 베스트**(또는 비슷한 메뉴)와 **골드박스**를 둘러봐.
4. 아래 조건을 **모두** 만족하는 상품만 골라.

| 조건 | 기준 |
|---|---|
| 영상 궁합 | 사진만 봐도 "이게 뭐에 쓰는 건지" 3초 안에 알 수 있음 |
| 쓰임새 | 좁은 집, 청소, 정리, 요리, 반려동물처럼 일상의 불편을 해결하는 물건 |
| 평판 | 별점 4.5 이상, 상품평 100개 이상 (많을수록 좋음) |
| 가격 | 5,000원 ~ 50,000원 (충동구매가 쉬운 가격대) |
| 사진 | 대표 사진이 선명하고, 제품이 크게 나오고, 글자가 너무 많지 않음 |

5. 아래에 해당하면 **절대 고르지 마.**
   - 건강기능식품, 영양제, 의약품, 의료기기, 다이어트·체중 관련 상품
   - 주류, 담배·전자담배, 성인용품, 무기류, 도박 관련
   - 화장품 중 "미백·주름·탈모 개선" 같은 기능성 효과가 핵심인 상품
   - 유아용 카시트·안전용품처럼 안전이 핵심인 상품
   - 애플·삼성처럼 유명 브랜드 전자제품 (브랜드 영상과 경쟁해서 불리함)
   - `products.txt`에 이미 있는 상품 (상품명이 비슷해도 같은 물건이면 제외)
6. 카테고리를 골고루 섞어. 한 카테고리에서 3개를 넘기지 마.

## 3단계: 링크 만들기
상품 하나마다 아래를 반복해.
1. 파트너스에서 그 상품의 **링크 생성**(또는 "링크 만들기") 버튼을 눌러.
2. 나오는 **단축 URL**(https://link.coupang.com/a/... 형태)을 복사해. 긴 URL이나 이미지 배너 코드가 아니라 단축 URL이어야 해.
3. 상품 페이지를 새 탭으로 열어 **대표 사진**을 찾아. 사진을 우클릭 → **이미지 주소 복사**를 해. `https://`로 시작하고 `.jpg`나 `.png`, `.webp`가 들어간 주소여야 해.
4. 상품명은 **15자 안팎으로 간단히** 줄여. 브랜드명, 용량, 색상 옵션, 괄호 속 설명은 빼.
   - 예: "OO리빙 접이식 실리콘 설거지통 대형 (그레이/베이지) 1+1" → "접이식 실리콘 설거지통"

## 4단계: products.txt에 추가
1. `products.txt` **맨 아래에** 한 상품당 한 줄씩 이 형식으로 추가해. 칸 구분은 ` | `(띄어쓰기, 세로 막대, 띄어쓰기)야.
   ```
   단축링크 | 간단한 상품명 | 대표 사진 주소
   ```
   예:
   ```
   https://link.coupang.com/a/bXyZ12 | 접이식 실리콘 설거지통 | https://thumbnail.coupangcdn.com/.../abc.jpg
   ```
2. 기존 줄은 절대 지우거나 순서를 바꾸지 마.
3. 저장한 뒤 파일을 다시 열어서, 새 줄이 모두 이 형식인지 확인해. 칸이 3개가 아닌 줄이 있으면 고쳐.

## 5단계: 기록
`cowork/기록/오늘날짜.md`에 추가한 상품명과 카테고리를 적어. 고르다가 제외한 상품 중 애매했던 게 있으면 이유와 함께 "사람이 확인할 것"에 적어.
