# 작업: 영상 검수·업로드 (매일 13:30, 20:30)

먼저 이 폴더의 `cowork/00-공통-규칙.md`를 읽고 그 규칙을 지켜.

## 목표
프로그램이 만든 영상을 **사람처럼 꼼꼼히 검수**하고, 통과한 영상만 YouTube Studio에 올려. 한 번 실행할 때 **최대 2개**까지만 처리해.

---

## 1단계: 대기 중인 영상 찾기
1. `output/` 폴더 안에서 **`READY` 파일이 있는 폴더**를 모두 찾아. 폴더 이름은 `20260924-123000`처럼 날짜-시각이야.
2. 그중 `uploaded.txt`나 `rejected.txt`가 **이미 있는 폴더는 건너뛰어**.
3. 남은 폴더를 **이름이 빠른 순서(오래된 것부터)**로 최대 2개 골라.
4. 하나도 없으면 기록에 "대기 영상 없음"만 남기고 끝내.

폴더마다 2~5단계를 차례로 해.

---

## 2단계: 대본과 업로드 정보 읽기
1. `script.json`을 열어 아래를 확인해.
   - `title`: 영상 제목
   - `hook_title`: 영상 위쪽에 계속 떠 있는 문구
   - `scenes`: 장면 목록. 각 장면의 `narration`이 실제로 읽히는 내레이션이야.
   - `review`: 프로그램 안의 AI 심의 결과 (점수, 문제점)
2. `업로드정보.txt`를 열어 제목, 설명, 태그, 설정, 첫 댓글을 확인해.
3. 설명 안의 `👉 제품 보러 가기:` 뒤에 있는 **쿠팡 링크**를 적어 둬.

## 3단계: 제품 페이지와 대조
1. Chrome 새 탭에서 그 쿠팡 링크를 열어. 쿠팡 상품 페이지로 이동해야 해.
   - 페이지가 안 열리거나, "판매 종료"·"품절"이면 → **불합격** (사유: 판매 중지)
2. 상품 페이지의 **상품명, 대표 사진, 상세 설명, 옵션**을 봐.
3. 대본의 내레이션 문장을 하나씩 읽으면서, 모든 주장이 **상품 페이지에 실제로 나와 있는지** 확인해.
   - 예: 대본에 "접으면 3cm로 줄어요"라고 했다면, 상품 페이지에 비슷한 수치가 있어야 해.
   - 상품 페이지에서 찾을 수 없는 구체적 수치나 기능이 있으면 → **불합격** (사유: 근거 없는 주장 + 해당 문장)
   - "튼튼해요", "편해요" 같은 일반적인 표현은 괜찮아.

## 4단계: 영상 직접 보기
1. Chrome 새 탭 주소창에 `final.mp4`의 **전체 경로**를 `file:///` 뒤에 붙여서 열어.
   - Windows 예: `file:///C:/Users/이름/cloud/output/20260924-123000/final.mp4`
2. 영상 길이를 확인하고, 아래 **시점마다 일시정지해서 화면을 캡처**해 살펴봐.
   - 0.5초, 2초, 전체의 1/3, 절반, 2/3, 끝나기 1초 전
3. 소리는 들을 수 없으니, 내레이션 내용은 `script.json`으로 확인한 것으로 대신해.

### 검수 체크리스트
하나라도 **[필수]** 항목에 걸리면 불합격이야. **[권장]** 항목은 기록에만 남기고 통과시켜.

**화면**
- [필수] 맨 위에 **"광고 · 쿠팡 파트너스…"** 문구가 처음부터 끝까지 보인다
- [필수] 제품 카드 아래 노란 **"프로필 링크 N번"** 배지가 보인다
- [필수] 가운데 제품 카드에 나오는 물건이 **쿠팡 상품 페이지의 대표 사진과 같은 제품**이다
- [필수] 움직이는 클립에서 제품 모양·색·로고가 **눈에 띄게 변형되지 않았다** (갑자기 다른 물건으로 바뀜, 손가락이 6개, 글자가 뭉개짐 등이 있으면 불합격)
- [필수] 자막에 **깨진 글자**(□, ?, 이상한 기호)가 없다
- [필수] 자막이 화면 밖으로 잘리지 않고 읽을 수 있다
- [필수] 화면 전체가 검거나 하얀 구간이 1초 넘게 이어지지 않는다
- [권장] 위쪽 훅 제목이 두 줄을 넘지 않는다
- [권장] 제품 사진이 너무 작거나 흐리지 않다

**길이와 형식**
- [필수] 영상 길이가 **15초 이상, 60초 이하**다
- [필수] 세로 화면이다 (가로가 세로보다 짧다)

**문구 (script.json과 업로드정보.txt)**
- [필수] 아래 표현이 제목·내레이션·자막·설명 어디에도 **없다**
  - "제가 써봤는데", "직접 써보니", "한 달 사용 후기"처럼 **직접 써 본 척하는 말**
  - "최저가", "1위", "역대급 할인", "무조건", "100%", "완벽"
  - 병을 고치거나 막는다는 말, 살이 빠진다는 말, "피부가 좋아진다" 같은 효능
  - 구체적인 가격 ("9,900원" 같은 금액)
  - 욕설, 비하, 성적인 표현, 특정인이나 경쟁 브랜드 비방
- [필수] 설명에 **"이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."** 문장이 그대로 있다
- [필수] 설명과 첫 댓글에 같은 쿠팡 링크가 있다
- [필수] 설명·첫 댓글·영상 마지막 장면의 **"프로필 링크 N번"** 번호가 모두 같다 (`script.json`의 `item_no`)
- [필수] 제목이 100자 이하이고 `#shorts`가 들어 있다
- [권장] 맞춤법이 자연스럽다. 제목·설명의 가벼운 오타는 업로드할 때 **고쳐서 올리고** 기록에 적어. 영상 속 자막 오타는 고칠 수 없으니 뜻이 바뀌는 오타일 때만 불합격시켜.

**중복**
- [필수] 최근 7일 안에 같은 상품으로 올린 영상이 없다. `data/state.json`의 `videos`에서 `topic`과 `created`를 비교해.

## 5-A단계: 불합격일 때
1. 그 폴더에 `rejected.txt`를 만들고 이렇게 적어.
   ```
   불합격 YYYY-MM-DD HH:MM
   - 사유 1 (체크리스트 항목과 구체적 내용, 몇 초 지점인지)
   - 사유 2
   ```
2. 그 폴더의 `READY` 파일을 지워.
3. 영상은 지우지 마. 사람이 나중에 확인할 거야.
4. 기록의 "사람이 확인할 것"에 폴더 이름과 사유를 적어.

## 5-B단계: 합격이면 YouTube Studio에 업로드
**`업로드정보.txt`의 내용을 한 글자도 바꾸지 말고 그대로** 옮겨 적어. 체크리스트에서 허용한 제목·설명 오타 수정만 예외야.

1. Chrome 새 탭에서 https://studio.youtube.com 을 열어. 로그인 화면이 나오면 멈춰.
   - 오른쪽 위 프로필이 **이 채널("쓸모템")**인지 확인해. 다른 채널이면 프로필을 눌러 채널을 바꾸고, 바꿀 수 없으면 멈춰.
2. 오른쪽 위 **만들기(카메라+ 아이콘) → 동영상 업로드**를 눌러.
3. **파일 선택**을 누르고 그 폴더의 `final.mp4`를 골라.
4. **세부정보** 화면
   1. **제목**: 칸 안의 기본 글자(파일 이름)를 모두 지우고 `[제목]`을 붙여 넣어.
   2. **설명**: `[설명]` 전체를 붙여 넣어. 줄바꿈과 링크가 그대로인지 확인해.
   3. **미리보기 이미지**: 건드리지 마. 쇼츠는 자동으로 정해져.
   4. **재생목록**: 건드리지 마.
   5. **시청자층**: **"아니요, 아동용이 아닙니다"**를 골라.
   6. **자세히 보기(더보기)**를 눌러 펼쳐.
      - **유료 프로모션**: "동영상에 간접 광고, 스폰서십, 보증 광고와 같은 유료 프로모션이 포함되어 있음"을 **체크**해.
      - **변경되거나 합성된 콘텐츠**: **"예"**를 골라. (AI 음성과 AI 영상 클립을 쓰기 때문)
      - **태그**: `[태그]`의 쉼표로 구분된 단어들을 붙여 넣어.
      - **언어 및 자막**: 동영상 언어를 **한국어**로.
      - **카테고리**: `[설정]`의 카테고리 (보통 **노하우/스타일**).
      - **댓글**: "모든 댓글 허용" 대신 **"부적절할 수 있는 댓글은 검토를 위해 보류"**가 있으면 그걸 골라.
   7. **다음**을 눌러.
5. **동영상 요소** 화면: 아무것도 추가하지 말고 **다음**.
6. **검토(확인)** 화면: 저작권 확인이 끝날 때까지 기다려 (최대 3분).
   - "문제 없음"이면 **다음**.
   - 저작권 문제가 나오면 **업로드하지 말고** 창을 닫아 초안으로 남긴 뒤, 5-A단계처럼 불합격 처리해 (사유: 저작권 확인 문제 + 화면 내용).
7. **공개 상태** 화면: `[설정]`의 공개 상태(보통 **공개**)를 고르고 **게시**를 눌러.
8. 게시 후 나오는 창의 **동영상 링크**(https://youtube.com/shorts/... 또는 https://youtu.be/...)를 복사해.

## 6단계: 첫 댓글 달고 고정
1. 복사한 링크를 새 탭에서 열어. 방금 올린 영상이 재생되는지 확인해. 처리 중이라고 나오면 1분 기다렸다 새로고침해.
2. 댓글 창을 열고, `[첫 댓글]`의 내용을 **채널 계정으로** 달아.
3. 방금 단 댓글의 **⋮(더보기) → 고정**을 눌러 맨 위에 고정해.
   - 쇼츠 화면에서 고정 메뉴가 없으면, YouTube Studio → **댓글** 메뉴에서 그 댓글을 찾아 고정해.

## 7단계: 결과 남기기
1. 그 폴더에 `uploaded.txt`를 만들고 **첫 줄에 영상 링크만** 적어. 프로그램이 이 파일에서 영상 ID를 읽어 가.
   ```
   https://youtube.com/shorts/AbCdEfGhIjK
   업로드 YYYY-MM-DD HH:MM, 첫 댓글 고정 완료
   ```
2. 그 폴더의 `READY` 파일을 지워.
3. 링크 페이지(`linkpage/`)는 프로그램이 `uploaded.txt`를 읽고 자동으로 갱신하니 직접 고치지 마.
4. 기록에 폴더 이름, 제목, 링크, 체크리스트의 [권장] 지적 사항을 적어.

## 중간에 막혔을 때
- 업로드 도중 오류가 나면 Studio의 **콘텐츠** 메뉴에서 **초안**으로 남았는지 확인해. 초안이 있으면 거기서 이어서 해. 같은 영상을 두 번 올리지 마.
- 게시는 됐는데 링크를 못 찾았으면 Studio → **콘텐츠 → Shorts**에서 방금 올린 영상을 찾아 링크를 복사해.
- 하루에 업로드 한도에 걸렸다는 메시지가 나오면 멈추고 `READY`를 그대로 둬. 다음 실행 때 다시 시도하게 돼.
