# 작업: 댓글 관리 (매일 22:00)

먼저 이 폴더의 `cowork/00-공통-규칙.md`를 읽고 그 규칙을 지켜.

## 목표
오늘 올라간 영상의 링크 댓글이 고정돼 있는지 확인하고, 프로그램이 놓친 댓글을 정리해.

프로그램도 30분마다 댓글에 자동으로 답해. 그래서 너는 **답글을 새로 많이 달 필요가 없어.** 확인과 정리가 주된 일이야.

## 1단계: 고정 댓글 확인
1. Chrome에서 https://studio.youtube.com 을 열고 채널이 "쓸모템"인지 확인해.
2. **콘텐츠 → Shorts**에서 최근 **48시간** 안에 게시된 영상을 모두 찾아.
3. 영상마다 쇼츠 화면에서 댓글을 열어, 맨 위에 **채널이 단 "👉 https://link.coupang.com/…" 댓글이 고정**돼 있는지 봐.
   - 고정돼 있으면 넘어가.
   - 채널 댓글은 있는데 고정이 안 됐으면 **⋮ → 고정**해.
   - 채널 댓글 자체가 없으면, 그 영상의 설명란에서 쿠팡 링크를 찾아 아래 형식으로 달고 고정해.
     ```
     제품 정보는 여기서 확인하세요!
     👉 (설명란의 쿠팡 링크)
     (광고 · 쿠팡 파트너스 활동으로 수수료를 받을 수 있어요)
     ```

## 2단계: 댓글 점검
1. Studio 왼쪽 메뉴 **댓글**로 가서 **"답글 달지 않음"** 필터로 최근 24시간 댓글을 봐.
2. 댓글을 하나씩 아래 기준으로 분류해.

| 종류 | 예시 | 할 일 |
|---|---|---|
| 구매·링크 질문 | "어디서 사요?", "링크 주세요" | 답글: "프로필 링크에서 N번을 찾아보세요! 😊" (N은 그 영상 설명란의 번호) |
| 제품 질문 | "사이즈 어때요?", "식세기 돼요?" | 상품 페이지에서 **확실히 확인되는 것만** 1~2문장으로 답해. 확인이 안 되면 "상품 페이지 상세 정보에서 확인해 보세요!"라고 답해. |
| 칭찬·공감 | "이거 좋네요", "저도 샀어요" | 하트(♥)만 눌러. 답글은 하루 5개까지만. |
| 불만·반박 | "별로던데요", "비싸요" | 방어하거나 따지지 마. 답글 없이 두고 기록에 적어. |
| 스팸·광고·욕설 | 다른 링크 도배, 성인 광고, 욕설 | **검토를 위해 보류** 또는 **삭제**를 눌러. 판단이 애매하면 보류해. |
| AI 여부 질문 | "AI 목소리죠?" | 솔직하게: "네, AI 음성으로 만들고 있어요. 제품은 직접 골라요!" |

3. 답글 규칙
   - 가격, 할인, 배송일, 재고는 **약속하지 마.** 바뀔 수 있어.
   - 효능이나 안전성을 보장하는 말은 하지 마.
   - 같은 문장을 복사해서 여러 곳에 달지 말고, 조금씩 다르게 써.
   - 한 번 실행에 답글은 **최대 15개**까지만 달아.

## 3단계: 기록
기록에 아래를 적어.
- 고정 처리한 영상 수
- 답글 수, 보류·삭제한 댓글 수
- 반복해서 나오는 질문이나 불만 (다음 영상 대본에 반영할 만한 것)
- 불만·반박 댓글 요약 (사람이 확인할 것)
